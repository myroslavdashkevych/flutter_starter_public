# Flutter Starter

A template for small and medium Flutter mobile apps (Android and iOS) that need to reach the
stores fast: a small working app that shows the architecture, stack and conventions every new
project starts from. Developers and AI agents work on it together under one documented
process, with the focus on maintainability and scalability.

- Documentation, starting with how to run the app: [doc/README.md](doc/README.md)
- Starting a new project from this template: [doc/guide/new-project.md](doc/guide/new-project.md)
